Repeat-sales workbench

重复成交不是简单平均

用相邻有效成交构造对数价格比，按月份估计指数；显式处理拆分合并、翻修、缺秩月份图、同屋相关与异常成交。

计算说明

1. 数据与样本

所有标识均为虚构。可载入样本、上传 JSON，或粘贴符合 schema 的数据。

2. 可算清的小例核对

同一组纯函数断言同时用于 npm test，核对基准归一化、权重、区间、缺秩和拦截规则。

3. 两份完整计算

A 与 B 分别在 Web Worker 中重估；返回消息带槽位和版本号，过期结果不会覆盖新规则图表。

4. 比较两份完整计算

比较的是各自返回的完整结果对象；不会把 B 的翻修规则写进 A 的图，反之亦然。

5. 从指数月份追到房屋

点击任一指数点或比较图中的月份，查看进入该月设计列的配对、价格比、权重、残差和翻修。

6. 配对与规则影响

每一行都是相邻有效成交或错误合并样本中的跨实体候选；筛选器显示当前规则改变了哪些配对。

纯静态、无第三方图表依赖。启动：npm start 后访问 http://localhost:4173；测试：npm test。
