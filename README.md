# 重复成交指数实验室（Repeat-Sales Lab）

一个零第三方运行时依赖的静态网页，用来演示如何正确处理同一房屋的重复成交。它不把多次成交金额直接平均，而是：

1. 按房屋和日期构造**相邻两次有效成交**；
2. 生成对数价格比 \(r_i=\log(P_{i,2}/P_{i,1})\)；
3. 用重复成交设计矩阵估计月度对数指数；
4. 把拆分合并、翻修、缺秩月份图、同屋多对相关、异常成交和错误实体合并分开处理；
5. 支持从指数月份追溯到具体房屋和配对，并在 A/B 两个后台计算槽中比较两份完整结果。

## 输入 JSON schema

所有标识和金额均为虚构。最小结构：

```json
{
  "meta": { "name": "示例" },
  "transactions": [
    { "id": "T1", "propertyId": "H1", "date": "2024-01-15", "price": 100000 },
    { "id": "T2", "propertyId": "H1", "date": "2024-03-15", "price": 110000 }
  ],
  "renovations": [
    { "id": "R1", "propertyId": "H1", "date": "2024-02-01", "cost": 12000, "type": "kitchen" }
  ],
  "structureEvents": [
    {
      "id": "S1",
      "type": "split",
      "date": "2024-02-20",
      "from": ["H1"],
      "to": ["H1A", "H1B"]
    },
    {
      "id": "BAD1",
      "type": "entity_merge",
      "date": "2024-09-01",
      "ids": ["H7", "H8"],
      "status": "erroneous",
      "note": "错误实体合并"
    }
  ]
}
```

支持的别名：`sales`、`amount`、`houseId`、`splitMergeRecords` 等。`status` 为 `void/cancelled/invalid/deleted` 的成交不会进入“有效成交”序列。

## 配对规则

对每个 `propertyId`：

- 过滤出日期、金额和状态有效的成交；
- 按日期排序；同日成交优先使用可选 `seq`，否则保留源文件顺序；
- 只把排序后的相邻两次有效成交作为候选，不构造所有两两组合；
- 检查两次成交之间是否存在涉及该房屋的拆分、合并、拆除或重建记录；
- 结构事件落在闭区间 `[firstDate, secondDate]` 内时，该配对标记为 `structure_barrier` 并排除；
- 同日成交标记 `same_day`；同月但不同日标记 `same_month`。它们的月份设计行是同一列上的 `-1/+1`，正好抵消，不能识别月度涨幅；
- `status: "erroneous"` 的实体/身份合并不会被当成物理拆分合并。系统会单独生成“如果沿用错误链接会形成什么跨房屋配对”的候选，默认以 `erroneous_entity_merge` 拦截。取消勾选拦截只会在对应计算槽中演示污染，不会影响另一槽。

## 指数模型

对跨月配对 \(i\)，设首次成交月为 \(b_i\)、第二次为 \(s_i\)：

\[
r_i=\log(P_{i,s}/P_{i,b})
\]

基础重复成交回归为：

\[
r_i=\sum_m D_{im}\beta_m+\varepsilon_i,
\qquad
D_{i,b_i}=-1,\ D_{i,s_i}=+1.
\]

指数为：

\[
I_m=100\exp(\beta_m-\beta_{b}).
\]

基准月 \(b\) 满足 \(I_b=100\)。页面使用对数轴显示指数，置信区间也先在对数尺度计算再指数化。

### 权重

- `equal`：\(w_i=1\)；
- `interval`：\(w_i=1/(A+B h_i)\)，其中 \(h_i\) 是两个月之间的月份跨度，默认 \(A=0,B=1\)，因此一个月配对权重为 1，两个月配对权重为 \(1/2\)。

权重公式和 \(A,B\) 都显示在界面中，配对表逐行给出最终权重。

### 同屋多对的相关性

同一房屋三次成交会产生两对相邻配对；中间成交价格误差会同时进入 \(-u_2\) 和 \(+u_2\)，因此配对误差并不独立。页面默认按 `propertyId` 聚类，使用 Liang–Zeger 型聚类稳健三明治协方差：

\[
\widehat V
=c(X'WX)^{-1}
\left(\sum_g X_g'W_ge_ge_g'W_gX_g\right)
(X'WX)^{-1},
\]

其中 \(c=\frac{G}{G-1}\frac{n-1}{n-k}\)。只有一个房屋簇的连通段无法得到可靠聚类稳健区间，会明确告警并回退到模型方差。

## 缺秩和断开的月份

把每个月份看成节点，把每条最终采用的配对看成无向边。月份图的每个连通段都有一个无法从数据识别的整体价格水平，因此全局设计矩阵的零空间维数等于连通组数量（包括没有任何边的孤立日历月）。

程序：

- 枚举首末成交月之间的全部日历月；
- 用并查集求连通分量；
- 报告月份列数、秩和零空间维数；
- 每个可估计连通段分别丢弃一个锚点月并归一化到 100；
- 孤立月或不同连通段之间不画连续插值线；
- 主图只连接日历上相邻且属于同一连通段的月份，下方另有月份连接弧图。

因此“断开月份”样本会显示 `100, 105, 110, 缺口, 缺口, 100, 104, 108`。两个 100 只是各段自己的基准，不代表两段市场水平相同。

## 翻修策略

翻修记录日期落在 `[firstDate, secondDate]` 内即视为持有期内翻修。页面提供：

1. **排除**：含持有期翻修的配对标记为 `renovation_holding_period`，不进入回归；
2. **独立项建模**：
   \[
   r_i=\sum_mD_{im}\beta_m+\gamma q_i+\varepsilon_i,
   \qquad q_i=\frac{\text{翻修成本}}{\text{首次成交价}}.
   \]
   若翻修没有成本但有记录，则 \(q_i=1\) 作为指示变量。若 \(\gamma\) 与月份效应共线，矩阵秩检查会识别并拒绝强行解释该系数；
3. **敏感性范围**：令 \(\alpha\) 为翻修成本被市场价值承认的比例，
   \[
   r_i(\alpha)=r_i-\alpha q_i.
   \]
   页面完整运行 \(\alpha=0\)（不扣减，指数上界）和 \(\alpha=1\)（按成本/前价全额扣减，指数下界），并显示区间带；
4. **不处理（对照）**。

配对表和 A/B 配对集合差异会明确列出每种策略排除、纳入或改变了哪些 ID。

## 异常成交

异常处理与缺秩、聚类分开：

- 先按当前规则拟合；
- 对残差计算中位数和 MAD；
- 稳健标准尺度为 \(1.4826\,\mathrm{MAD}\)，得到稳健 \(z\)；
- 当 MAD 为 0 时回退到残差标准差；
- 同时使用透明的绝对对数残差阈值（默认约 \(\log 2\)），避免“过半残差完全相同导致 MAD=0 后单个巨额异常无法识别”；
- 可选择仅标记、剔除或 Huber 降权。

剔除一条“桥接边”可能改变月份图连通性，因此剔除后会重新构造连通分量并重新拟合，而不是在旧图上继续画线。

## 后台重估和结果隔离

`src/worker.js` 调用同一个纯函数 `analyzeRepeatSales(dataset, config)`。每次运行带：

- `slot: "A" | "B"`；
- 递增的 `nonce`；
- `jobId`。

Worker 返回时，UI 只在 `slot` 对应卡片且 `nonce` 仍是该槽最新版本时写入结果。过期回复会被忽略。A 的配置、状态、图表和结果对象不会写入 B；比较区只读取两份已经完成的完整结果。

## 可算清的小例

内置“小例核算”和 `npm test` 共用 `src/core/selfCheck.js`。其中一个两配对加权例子为：

\[
X=(1,1)^\top,\quad y=(0.1,0.2)^\top,\quad w=(1,0.5).
\]

于是：

\[
\hat\beta=\frac{0.1+0.5(0.2)}{1+0.5}=\frac{2}{15}.
\]

两簇的残差为 \(-1/30\) 和 \(1/15\)。小样本修正 \(c=2\) 后：

\[
SE_{\text{cluster}}
=\sqrt{\frac{2[(-1/30)^2+(1/30)^2]}{(3/2)^2}}
=\frac{2}{45}.
\]

三所独立房屋在 1 月和 2 月分别产生 `100→108`、`100→110`、`100→112` 时，2 月指数为：

\[
100(1.08\times1.10\times1.12)^{1/3}.
\]

测试还核对：

- 基准月指数必须为 100；
- 一个月和两个月间隔权重分别为 1、1/2；
- 断开样本有 8 个月份列、秩 4、两个可估计连通段；
- 同日成交不进入月份设计；
- 错误实体合并默认被拦截。

## 方法边界

这是一个透明的教学和核查工作台，不是生产级房价指数系统。它使用 Wald/正态近似区间，未实现 Case–Shiller 两步方差加权、嵌套 GLS、重复销售修正或非同步交易修正；这些模型可以在当前纯函数核心上继续扩展。页面不会对不可识别月份做插值，也不会给跨连通段的指数水平编造统一基准。
